# KeyForge

This is a simple password generator application built using Python and the Tkinter library. It allows users to generate random passwords based on selected criteria such as length, character types, and additional formatting options like Apple-specific formatting.

## Features

- **Customizable Password Length**: Users can select a password length between 4 and 32 characters.
- **Character Type Selection**: Users can choose to include lowercase letters, uppercase letters, digits, and symbols in the password.
- **Apple Formatting**: An option to format the password in an Apple-specific format (18 characters, grouped in 6-character segments separated by hyphens).
- **Copy to Clipboard**: Generated passwords can be easily copied to the clipboard with a single button click.

## How to Use

1. **Set Password Length**: Use the slider to select the desired password length.
2. **Select Character Types**: Check the boxes to include lowercase letters, uppercase letters, digits, and/or symbols in the password.
3. **Choose Extra Features**: Select "Apple Formatting" from the dropdown menu if you need a password formatted for Apple devices.
4. **Generate Password**: Click the "Generate Password" button to create a password based on your selections.
5. **Copy Password**: Click the "Copy to Clipboard" button to copy the generated password to your clipboard.

## Requirements

- Python 3.x
- Tkinter (usually comes pre-installed with Python)

## Installation

1. Clone the repository or download the `bot.py` file.
2. Ensure you have Python installed on your system.
3. Run the script using the following command:

   ```bash
   python bot.py
   ```
