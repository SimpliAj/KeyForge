About the Project

KeyForge is a lightweight, open-source password manager built out of curiosity and boredom—but designed with security in mind.

Written in Python, it runs on Windows, macOS, and Linux directly from a USB drive, requiring no installation. Your credentials, notes, and attachments are stored in an encrypted, offline vault, giving you full control over your data. Keep it local, take it with you, or store it wherever you choose—without relying on cloud services.

Get Started

To get started with KeyForge, simply download the latest release from our GitHub page. KeyForge runs directly from a USB drive on Windows, macOS, and Linux—no installation required.

For advanced users, you can also build KeyForge from source by following the installation guide.
